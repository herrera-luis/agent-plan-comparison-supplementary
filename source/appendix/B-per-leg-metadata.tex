\section{Per-leg metadata}
\label{app:metadata}

Per-leg metadata is recorded in \texttt{metadata.json} files alongside
each canonical artefact, organised one directory per
(model, benchmark, tool, leg) cell under \texttt{runs/}. The fields
relevant to the rubric are summarised in
Table~\ref{tab:metadata-plan} (planning legs) and
Table~\ref{tab:metadata-exec} (execution legs); both tables report all
48 (tool $\times$ benchmark $\times$ leg $\times$ model) primary
cells under Claude Opus~4.8 and GPT-5.5.
